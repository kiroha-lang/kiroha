# Kiroha icon and favicon

Kiroha's icon is an ivory **K** growing into a soft green leaf, on a forest-green
background. It appears in the header of these pages; the browser tab uses its
favicon version.

![Kiroha: an ivory K growing into a sage-green leaf on a forest-green background](assets/kiroha-icon-128.png){ width="128" height="128" }

## Download the icon

- [Original PNG — 1254×1254](assets/kiroha-icon.png), for avatars and larger displays.
- [Small web PNG — 128×128](assets/kiroha-icon-128.png), for headers and compact layouts.

Both versions have an opaque green background and square proportions.

## Small icons for browser tabs

The same design stays recognizable at favicon sizes:

| 16×16 | 32×32 |
| --- | --- |
| ![Kiroha favicon at 16 pixels](assets/favicon-16.png){ width="16" height="16" } | ![Kiroha favicon at 32 pixels](assets/favicon-32.png){ width="32" height="32" } |

Download a [multi-size ICO](assets/favicon.ico) containing 16×16, 32×32 and 48×48
frames, or the individual [16px PNG](assets/favicon-16.png) and
[32px PNG](assets/favicon-32.png).

For another website, copy the favicon files beside the page and add:

```html
<link rel="icon" href="favicon.ico" sizes="16x16 32x32 48x48">
<link rel="icon" type="image/png" href="favicon-32.png" sizes="32x32">
<link rel="icon" type="image/png" href="favicon-16.png" sizes="16x16">
```

The repository's [branding asset guide](../assets/branding/README.md) records the
original generation prompt and the size/format conversion commands.
